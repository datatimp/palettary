What is Palettary?

Palettary is a curated collection of color primitives designed for modern design systems. Starting with a batch of color primitives helps speed up the initial design phase. Each palette includes color scales across multiple hues, making it easy to establish consistent, accessible color foundations for your projects. Export directly to Figma as variables, or download as CSS or plain text for use in any design tool or codebase.
